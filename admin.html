처음 한 번 · GitHub 연결 방법
  1. GitHub의 Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token을 여세요.
  2. 이름은 Cherry Soda Club, 만료 기간은 30일로 설정하세요.
  3. Repository access에서 Only select repositories → -cherrysoda-club만 선택하세요.
  4. Repository permissions → Contents: Read and write를 선택하고 생성하세요. Metadata 읽기는 자동으로 포함됩니다.
  5. 생성된 키를 위 입력란에 붙여넣고 GitHub 연결을 누르세요. 키는 이 페이지를 닫거나 새로고침하면 지워집니다.

연결 키는 비밀번호처럼 취급해주세요. 키를 채팅에 보내지 마세요. 내용과 업로드 사진은 공개 사이트에 표시됩니다.
